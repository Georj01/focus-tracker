# Pomodoro App

Small Pomodoro application built with Create React App.

## What's included

- `src/App.js` - Example root component (generated by CRA).
- `src/Pomodoro.js` - Main Pomodoro timer logic and UI.
- `src/TaskList.js` - Component rendering the task list (edit, mark complete, delete).
- `src/Stats.js` - Presentational component showing basic statistics.
- `public/index.html` - Main HTML where React mounts the app.
- Configuration and support files: `serviceWorkerRegistration.js`, `reportWebVitals.js`, `setupTests.js`.

> The files contain comments explaining their purpose and internal logic.

## Implemented Features (current state)

- Pomodoro timer with modes: `work`, `shortBreak`, `longBreak`.
- Timer controls: start, pause, and reset.
- Customizable times from the UI (in minutes).
- Tasks: add, edit, delete, and mark as complete (in-memory persistence - current session).
- Basic statistics shown in `Stats` (work/break/cycles) — simple in-memory calculation.
- Dark mode toggle (basic UI).
- Explanatory comments added in main files.

## How to run (Windows PowerShell)

Open a terminal in the `pomodoro-app` folder and run:

```powershell
npm install
npm start
```

The app will open at `http://localhost:3000` if no other process is using that port.

## Development and testing

- Basic tests generated by CRA in `src/App.test.js`.
- To run tests:

```powershell
npm test
```
